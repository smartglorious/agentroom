# Security Policy

## Supported version

Security fixes are applied to the latest released version of AgentRoom.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** option in the Security tab of this repository so details can be reviewed privately.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include real credentials or private user data. You should receive an acknowledgement within seven days.
