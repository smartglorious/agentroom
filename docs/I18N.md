# Giao diện hai ngôn ngữ (Tiếng Việt / English)

Đặt `agentroom.language`: `vi` (mặc định, nên nâng cấp không đổi gì), `en`, hoặc `auto` (theo ngôn ngữ hiển thị của VS Code). Đổi xong giao diện chat tự tải lại; không cần khởi động lại VS Code.

## Dịch cái gì

| Phần | Theo `agentroom.language` | Ghi chú |
|---|---|---|
| Giao diện chat (webview): tab, nút, thẻ, tooltip, ô nhập | ✔ | |
| Hộp thoại, thông báo, lệnh nhập liệu của extension | ✔ | |
| Tin hệ thống trong chat (cảnh báo ngân sách, hạn mức gói, giới hạn lượt, lỗi worker, chế độ tự chủ…) | ✔ | Lưu trong `chat.jsonl` bằng ngôn ngữ **lúc đăng**; không dịch lại tin cũ khi đổi ngôn ngữ |
| Telegram: lệnh, trả lời, nút, thẻ duyệt | ✔ | Cùng ngôn ngữ với VS Code/daemon đang chạy phòng |
| Báo cáo lỗi (`issues`), kết quả quét dọn dẹp, `README.txt` của lô dọn | ✔ | |
| CLI `agentroom-daemon` | ✔ | Ngôn ngữ: `agentroom-daemon set language vi|en|auto`, hoặc biến `AGENTROOM_LANG` (auto theo `$LANG`) |
| Tên lệnh trong Command Palette, mô tả cài đặt | theo **ngôn ngữ hiển thị của VS Code**, không theo `agentroom.language` | `package.nls.json` (English) / `package.nls.vi.json`. Cơ chế của VS Code |

## Không dịch (cố ý)

- **Prompt gửi cho worker** (`src/core/prompt.ts`), mô tả tool MCP, lý do chặn của chính sách tự chủ (`autonomy.ts`), nội dung `SOUL.md`/trí nhớ: là một phần của tiền tố prompt phải giữ nguyên giữa các lượt (CLAUDE.md, nguyên tắc 6). Đổi ngôn ngữ ở đó làm vô hiệu mọi session đang chạy và tốn token.
- Log của daemon/Telegram và tiêu đề trong bộ gom lỗi (`trVi`): giữ tiếng Việt để tìm bằng grep và để cùng một lỗi không tách làm hai khi đổi ngôn ngữ.
- Tài liệu trong `docs/` và thông báo lỗi khi đọc `workers.yaml` (`config.ts`): vẫn tiếng Việt. `README.md` có bản tóm tắt tiếng Anh bên dưới.

## Cho người sửa code

Chuỗi nguồn là **tiếng Việt và chính là khóa**: `tr("Đã ghi vấn đề {id}.", { id })`. Muốn thêm chuỗi hiển thị cho người dùng:

1. Viết `tr("văn bản tiếng Việt {tham_số}", { tham_số })` (webview `media/main.js` có `tr` riêng, cùng cú pháp).
2. Thêm bản tiếng Anh vào `src/core/i18n-en.ts` với đúng các `{tham_số}`.
3. Không gọi `tr` ở mức module (chạy trước khi ngôn ngữ được đặt): bọc trong hàm.

`test/i18n.test.ts` đỏ nếu: thiếu bản tiếng Anh, tham số lệch, bản dịch thừa không ai dùng, còn chữ Việt ngoài `tr(...)` ở các file giao diện, hoặc `package.nls*.json` lệch nhau.
